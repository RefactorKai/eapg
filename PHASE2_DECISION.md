## Gate 1. Prove isolation per invocation

The historical development runner shares a Bubblewrap PID namespace, user identity, and writable scratch across builds and executions. Test the replacement launcher with locally authored fixtures. Every preprocessing, compilation, and binary invocation must have private bounded scratch and an isolated process tree, with the supervisor protected from candidate signals. Probe host and network access, cross-run file and process visibility, output and aggregate resource bounds, and descendant cleanup after timeout and failure. Pin the tested launcher and limits before held-out profiling. - Verify that `r = r + 1;` retains the right-hand-side use of `r`, is classified as monotonic progress, and can be pruned when it is incidental to the causal update. Include a genuine reset control.
